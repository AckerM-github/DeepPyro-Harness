# M6 全量验收与兼容审计

- 前置：M5
- 估算：2–3 人日
- 写入范围：tests/（补齐）、docs（仅报告/清单）；**src 只允许修本卡发现且已 review 的缺陷**

## 目标

证明整套 goal 升级在真实链路上成立、与 DSH 语义一致、未启用 driver 时零回归。

## 子任务

### M6-1 集成矩阵
覆盖：create → 多 round 自动续行；中途 pause（running 时 cancel keepInbox）；人类消息插入竞争；
resume 后重驱；complete/blocked（工具路径）；round 上限 block；陈旧预留拒绝且消息恢复；
进程重启后 rehydrate 且 disarmed；fork 后 disarmed。

### M6-2 兼容与回归
- 未启用 driver 的会话：与基线逐记录 diff（允许的差异必须列出并解释）。
- DSH fixture 回放：goal/change 新记录能被 DSH 校验器接受（若已有回放工具）。
- 旧 {goal: "<string>"} 会话打开不丢 goal。

### M6-3 全量门禁
- uv run pytest -q 全量绿
- uv run ruff check src tests 干净
- events/catalog 一致性测试绿
- 本机沙箱限制（若 pytest 因临时目录失败）：在普通终端复跑，并在报告里注明环境。

### M6-4 审计报告
- 契约偏离清单（每条：位置、原因、是否已写进 spec/README）
- 未覆盖风险清单与建议下一轮任务。

## 验收

- [ ] 上述矩阵每格有测试
- [ ] 全量 pytest 绿（或在普通终端复跑的完整日志）
- [ ] 偏移清单为空或全部带解释
- [ ] 报告可交接给下一轮维护者

## 禁止

- 为了绿而放宽断言/跳过测试（skip 必须逐条说明）
- 无 review 的 src 改动

## 回报格式

任务ID / 矩阵覆盖表 / 全量测试输出摘要 / 偏移清单 / 遗留风险。

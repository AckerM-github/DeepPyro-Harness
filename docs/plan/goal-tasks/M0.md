## 子任务

1. **M0-1 记录 schema**：goal/change data 的完整字段（含 version、goals 快照、tombstone、revision），
   逐字段写类型/可空/默认；quote 源码类型定义。
2. **M0-2 状态机**：动词 × phase 转换矩阵、非法转换错误码、CAS 失败错误码、clear 语义、时间戳规则。
3. **M0-3 工具契约**：get_goal / create_goal / update_goal 的入参 schema、输出 JSON、错误码全集、
   人类轮次要求、blockedAfterConsecutiveRounds、autonomous complete/blocked 的 wrapup 与 turn 结束语义。
4. **M0-4 事件 payload**：goal/changed、goal/activation-changed、agent/inbox/inserted|claimed|discarded、
   agent/status 的精确字段与发送时机；注明 DSH 的 session/event 是服务内通道而非总线事件。
5. **M0-5 driver 不变量**：逐条对照 _rd.js，填满 spec 第 7 节的 8 组（ready/drive/预留/fence/失败路径/幂等/turn stop）。

7. **M0-7 UNRESOLVED**：列出证据不足、需人工决策的条目，每条写明“缺什么证据、影响哪张卡”。

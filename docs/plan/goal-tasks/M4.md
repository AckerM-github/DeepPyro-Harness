# M4 人类面：/goal 命令与 TUI 显示

- 前置：M2a + M3b
- 估算：1–2 人日
- 写入范围：src/deeppyro/builtin/commands_builtin.py、src/deeppyro/tui/（runtime/session_view 等）、
  src/deeppyro/headless.py、tests/tui/、tests/test_commands.py（或现有命令测试）

## 目标

人类能用命令完整管理 goal，并能看到 phase/round/activation；人类 resume 是 rearm 的唯一正常路径。

## 子任务

### M4-1 /goal 命令
- 子命令：/goal（展示）、/goal <text>（create）、/goal pause|resume|complete|clear|edit <text>。
- 注册进 commands_builtin 的 _ROWS 与 host handler；不支持参数时给出 usage。
- 输出格式固定（phase、round n/max、activation、blockedReason）。

### M4-2 TUI 展示
- 状态行或 session view 显示 goal 摘要；goal/changed、goal/activation-changed 触发刷新。
- 无 goal 时不出噪声。

### M4-3 人类路径语义
- /goal resume 负责 rearm（工具 resume 仍拒绝 paused）；会话恢复/fork 后 display 出 disarmed 状态。
- headless 模式支持展示（不要求交互式改写），保证脚本可观测。

### M4-4 测试
- 命令解析/输出快照；resume 后 activation 变化；恢复会话后 disarmed 可见。

# M1 状态机、记录与 activation

- 前置：M0 合入（docs/spec/goal.md 已冻结）
- 估算：2–3 人日
- 写入范围：src/deeppyro/goal/、tests/goal/、src/deeppyro/builtin/goal.py（仅服务接线）、
  tests/test_goal.py（迁移/改写成新语义）
- 谨慎触碰：src/deeppyro/core/wire.py（仅当 Message.source 需要收紧校验，改前先报告）

## 目标

GoalService v2：goal/change 写完整快照 + revision CAS + 6 个动词 + 严格 fold + 进程本地 activation。
本卡不做工具改名、不做 driver、不发新总线 payload（goal/changed 保持现有形状直到 M3b）。

## 子任务

### M1-1 快照记录 + CAS
- goal/change data 按 spec §2.1 写完整快照；clear 写带 revision 的 tombstone。
- 动词 create/edit/pause/resume/complete/block/clear；非法 phase 转换按 spec 拒绝并给错误码。
- CAS：{id, revision} 不匹配抛错，错误码取自 spec。
- 保留常量 GOAL_EVENT / GOAL_BUS_EVENT 名称不变。

### M1-2 严格 fold/replay
- 新增 goal/replay.py：从记录列表折叠出当前 goal；拒绝 malformed、revision 不连续、非法转换、时间戳非单调。
- 只有 goal 来源 user/message 推进 roundsStarted；处理不连续已准入 round 的拒绝规则。
- 旧格式兼容：读到 {goal: "<string>"} 折叠为 active、roundsStarted=0、maxGoalRounds=默认值的内存视图；**不回写**。

### M1-3 activation
- GoalService 维护进程本地 armed/disarmed；构造默认 disarmed。
- 会话开始边界 / agent 创建后必须 disarm；resume 动词 rearm（人类路径 M4 才接）。
- goal/activation-changed 暂不进总线（M3b 处理），但服务内部保留状态与接口。

### M1-4 回归与迁移
- tests/test_goal.py 5 个旧用例迁移到新语义（或标记为 legacy 兼容测试）。
- 新增 tests/goal/test_goal_state.py、test_goal_replay.py：状态矩阵、CAS、tombstone、fold、旧格式兼容，≥15 例。

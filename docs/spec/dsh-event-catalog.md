## Risks and limits

1. Compiled JavaScript erases the `Events` interface, so payload types are `unknown` unless a
   `.d.ts` survives in the asar. M2 must take payload evidence from call-site arguments.
2. Computed event names (`ctx.emit(`${ns}/${name}`)`) cannot be resolved statically; the count
   above is the residual risk for "P0 missing = 0".
3. A literal without a call site may still be a real event dispatched through a wrapper helper
   (`ctx[name]`, `events.dispatch`), or a record/const. These stay in "unclassified".
4. `approval/asked` and `approval/decided` are both bus events and session records. The bus copy
   is catalogued here; the record copy stays in the frozen 62-name vocabulary.
5. Presence of a name does not prove a consumer exists in DSH; `modes` only says how it is called.
